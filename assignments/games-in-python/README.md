
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Crie em Python um jogo da Forca no qual o jogador adivinha as letras de uma palavra escolhida aleatoriamente antes de esgotar suas tentativas. A atividade pratica manipulação de strings, listas, condicionais, laços de repetição e entrada de dados.

## 📝 Tarefas

### 🛠️ Preparação do Jogo

#### Descrição
Prepare a palavra secreta e as variáveis necessárias para acompanhar o andamento da partida.

#### Requisitos
O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Inicializar o estado do jogo para registrar as letras adivinhadas e as tentativas incorretas restantes.

### 🛠️ Rodadas e Resultado

#### Descrição
Implemente as rodadas para que o jogador tente adivinhar a palavra e receba informações atualizadas sobre seu progresso.

#### Requisitos
O programa concluído deve:

- Solicitar palpites de letras e mostrar o progresso da palavra no formato `_ _ _`.
- Atualizar e exibir as tentativas incorretas restantes.
- Encerrar quando a palavra for adivinhada ou as tentativas acabarem.
- Exibir uma mensagem de vitória ou derrota ao final da partida.
